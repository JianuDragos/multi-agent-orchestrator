# 🤖 Multi-Agent Orchestrator

An advanced multi-agent orchestration system that automates the analysis and modification of source code within a project. The system runs 100% locally using LLMs via [Ollama](https://ollama.ai/), guaranteeing absolute privacy for your data and code.

## 🌟 Key Features

- **Local & Fast Processing:** REST API communication with Ollama for minimal overhead and maximum response speeds.
- **Multi-Agent Architecture:**
  - 🧠 **Coordinator:** Analyzes the request, scans the project structure, and creates a detailed action plan (which files to modify, which to avoid, and why).
  - 🛡️ **Supervisor:** Acts as a safety net. It validates the coordinator's plan, prevents hallucinations (e.g., inventing non-existent files), and enforces strict safety constraints.
  - 👷 **Worker:** Takes the approved plan and generates concise, ready-to-execute instructions for a coding agent (e.g., Aider).
- **Smart Project Scanning:** Capable of analyzing massive projects through "skimming" techniques (extracting class/function structures from very large files to save the LLM's context window).
- **Robust JSON Validation:** Advanced mechanisms for securely extracting, repairing, and structurally validating JSON responses generated by the models.

## 📂 Project Structure

- `orchestrator.py` - The main entry point and the engine coordinating the agent workflow.
- `config.json` - System settings and agent role mappings to specific LLM models.
- `tools/`
  - `ollama_client.py` - Optimized REST client for interacting with Ollama (supports retries, timeouts, fallbacks).
  - `project_scan.py` - Utilities for building the directory tree and intelligently filtering relevant files.
  - `plan_validation.py` - Strict rule system for validating paths and logic within the agents' plans.
  - `json_utils.py` - Safe extraction of data structures from free-text LLM outputs.

## 🚀 System Requirements

- **Python 3.8+**
- **Ollama** installed and running on the default port (`http://localhost:11434`).
- The LLMs configured in `config.json` must be pulled locally (e.g., `ollama run llama3`).
